# v1.1.3 更新说明

> 发布时把「简介」那段填进 `version.json` 的 `notes`（长度必须 ≤ 2000 字），长版直接贴到 GitHub Release 正文。

## 简介（version.json 用）

【新增】
· 支持国际版 WorkBuddy：自动识别国内版 `~/.workbuddy` 或国际版 `~/.workbuddy-ai`
· 识别错了，点路径卡片标题右侧「国内版 / 国际版」一键切换，账号列表同步刷新
· 「携带全部技能」只显示摘要，不再铺开整份清单
· 「自定义技能」改用弹窗搜索勾选，已选技能在摘要里看数量
· 卡片说明收进标题旁的悬浮提示，版面更紧凑

【修复】
· 新电脑已登录但没聊过天，账号选不到的问题
· 选了账号却被静默换成另一个账号的问题

【下载】
替换旧程序即可，无需重新安装。

## 完整版（Release 正文用）

### 修好的问题

**1. 国际版用户路径全错（issue #1）**

以前三处都写死国内版：`WB_DIR` 常量、`read_workspace_root()` 的兜底、`local_env_from_prefs()` 直接沿用 prefs 里的旧路径。国际版用户第一次打开，两个框都是错路径，账号列表直接报「缓存目录里没有 workbuddy.db」。

现在：

- 启动时按 `~/<cache>/workbuddy.db` 是否存在识别版本，两套目录都存在时取**会话条数多的**那套（其次看数据库 mtime）。
- 工作空间兜底路径由缓存目录名反查，不再写死 `~/WorkBuddy`。
- prefs 里存过旧版本路径、但那个目录下没有 `workbuddy.db` 时，重新探测一次，不再拿死路径当默认值。

**2. 路径卡片上方新增「国内版 / 国际版」切换**

自动识别不可能覆盖自定义安装目录，所以给了手动纠正的入口：

```
WorkBuddy 版本  [国内版] [国际版]   识别错了点这里切换，两个路径会换成该版本的默认值
```

点击即通过现有 `/api/paths/save` 写入并刷新两张路径卡片，无需重启；手动编辑路径时不显示该切换条。

**3. 新电脑上已登录但零会话的账号选不到，且选了会被静默换掉**

- 账号清单以前只来自本机会话表，全新机器是空的；现在会从 `account-snapshot.json` 补入「已登录但没聊过天」的账号（保留 uid 原始大小写）。
- 更严重的是：以前即便选了这类账号，也会被判定为非法并回落成「会话最多的那个账号」，会话登记到别人名下、在左侧看不到。现在以「会话表 ∪ 账号快照」判定合法性，选的账号会被保住。
- 前端以前把错误吞掉了，现在会把原因显示在摘要行和弹窗里，比如「本机还没读到已登录的账号：先启动一次 WorkBuddy 并登录」。

### 交互优化

**4. 「携带技能」不再铺开整份清单，字段统一为垂直布局**

- 「携带技能」以前自占一行、下面还铺开一整份技能清单；现在面板上只留下拉框（+ 自定义模式下的「选技能」按钮）和一行摘要。「打包范围」「携带技能」「打包到哪个文件夹」都改成标签在上、控件在下，不再挤在同一行。
- 选「携带全部技能」：摘要写「携带全部技能：136 个 · 90.7 MB；1 个不可用技能已跳过」，不再渲染上百个条目。
- 选「自定义技能」：点「选技能」打开独立弹窗，搜索、全选、清空、刷新都在弹窗内完成。
- 弹窗是草稿态：改动只在点「确定」后生效，点「取消」或按 Esc 全部丢弃。

**5. 版面瘦身：说明移入悬浮提示，路径行压缩**

- 卡片标题旁新增一个小圆圈感叹号图标，鼠标悬停（或键盘聚焦）才展开说明，平时不占版面。原先压在标题下的整段说明文字已移除。
- 两个路径行的上下留白与锁按钮尺寸都做了压缩，卡片更紧凑。
- 「国内版 / 国际版」切换移到卡片标题行右侧，前面的冗余文字已去掉。

### 升级方式

下载 `WorkBuddy-Migrate-Win-v1.1.3.exe` 替换旧程序即可。已打包的迁移包不需要重做；旧版打出来的迁移包同样能被新版接收。
