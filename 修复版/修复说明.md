# 本次局部修复

支持按需携带技能和同名技能的跳过或覆盖选择，同时保留迁移检查、重复迁移及更新提醒的修复。

1. 浏览器检测补充用户安装目录和 PATH；使用系统默认浏览器成功打开后，继续保留网页服务，避免错误降级而失去“指定打包”选项。
2. 已有会话在源机 `updated_at` 更晚时，更新数据库、会话正文、相关索引和产出文件；时间相同或本机更晚则保留本机。已有会话保留原账号归属及目标数据库独有字段，新增会话仍使用界面选定的账号。
3. 文件拷贝改为比较实际内容，修复相同大小但内容已变化时被跳过的问题。
4. 检查迁移包时确认数据库文件存在，避免文件丢失后被创建为空库而误报 `no such table: sessions`；不把检查快照或本机备份当作源数据库。读取会话使用只读连接，空库和缺少会话表会给出具体提示。
5. 源机可选择不携带、携带全部或自定义勾选技能，列表展示名称、简介、大小，选中技能的完整目录及资源一起打包。全部迁移默认携带全部技能，指定迁移默认不携带，均可调整。连续打包生成独立目录，避免残留上次所选技能；`blobs` 等其他公共数据的打包方式不变。
6. 新技能直接导入，相同内容自动跳过；同名但内容不同的技能逐项选择跳过或覆盖，默认跳过，支持批量设置。覆盖前完整备份本机旧技能，再整目录替换，避免旧文件混入；拷贝失败恢复本次已替换的技能及数据库。
7. 有效技能链接、上级目录映射和内部资源链接按真实内容读取与打包。失效或循环链接仅标记对应技能不可用，在列表中显示原因，保留其他技能的选择与迁移；全部打包时明确记录跳过项。覆盖本机链接技能前备份其真实内容，替换技能入口而不修改外部原目录；失败恢复原链接。错误提示仅显示一次。

更新前备份本机数据库、将替换的文件及路径修复会改写的文件，备份失败即停止迁移。备份仍放在迁移包的 `_backup_日期时间` 文件夹，原文件按“缓存目录 / 工作空间”保存。已有会话的数据库更新在文件拷贝成功后提交；拷贝失败会报告错误、回滚数据库并恢复已备份文件，使其可以重试。若文件被占用导致恢复也失败，会明确提示备份位置。

原 EXE 保留在项目根目录。本目录的 `_修复版.exe` 可单独使用，不需要旁边的 Python 文件。

右上角开发者微信左侧的“更新”按钮使用 #4a7c3a 背景和紧凑尺寸，只有检查到新版才显示。启动时匿名读取公开版本信息，发现新版弹窗显示版本与说明；下载按钮打开公开 Release 页面。无新版或检查失败时入口隐藏，断网时不影响迁移。

已有会话更新采用较晚的会话时间作为判断依据；时间相同的内容冲突不自动合并。若所有浏览器都无法启动，仍沿用原有简化界面兜底，携带全部技能、同名技能跳过。
